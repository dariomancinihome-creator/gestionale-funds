# Gestionale Funds

Avvio locale:
`pip install -r requirements.txt`
`streamlit run app.py`

Per pubblicarlo: caricare i file su GitHub e collegare il repository a Streamlit Community Cloud, selezionando `app.py`.

Il pulsante INVIA registra la richiesta nello storico del gestionale. Non esegue direttamente operazioni bancarie.
